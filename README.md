# Mohamad Reza

### Machine learning · Computer vision · Natural language processing

I work on Python-based machine learning projects, with a focus on computer vision, language systems, and model evaluation.

## Selected projects

- [AskCael](https://github.com/adler1122/CineSuggest) — a terminal movie recommendation demo using retrieval-augmented generation.
- [Football MOT](https://github.com/MohamadRezaRS/football-mot) — YOLO-based tracking and pitch mapping for broadcast football video.
- [MetaDrive DQN](https://github.com/adler1122/metadrive-dqn) — reinforcement learning for autonomous driving in procedurally generated environments.
- [Chess AI](https://github.com/adler1122/Chess) — a custom chess engine with search-based AI opponents.
- [IMDb sentiment classifier](https://github.com/MohamadRezaRS/imdb-sentiment-classifier) — a PyTorch pipeline for movie review classification.
- [F1 PitWall](https://github.com/MohamadRezaRS/F1-PitWall) — pit-stop prediction using tabular models and a stacking ensemble.
