# Mohamad Reza

### Machine learning · Computer vision · Applied AI

I build Python projects that connect data preparation, modeling, evaluation, and usable software. My work spans computer vision, natural language processing, reinforcement learning, and predictive analytics.

## About me

I enjoy turning research ideas into working systems and testing them carefully. Recent projects include tracking football players from broadcast video, training an autonomous driving agent, and building models for text and tabular data.

## What I build

- **Computer vision:** object tracking, team clustering, and perspective mapping for sports video.
- **Machine learning:** feature engineering, model comparison, cross-validation, and out-of-sample evaluation.
- **AI applications:** natural language pipelines, reinforcement learning agents, and search-based game AI.

## Selected projects

- [Football MOT](https://github.com/MohamadRezaRS/football-mot) — tracks players, referees, and the ball, then maps their positions onto a 2D pitch.
- [MetaDrive DQN](https://github.com/adler1122/metadrive-dqn) — trains a driving agent in procedural environments and evaluates it on unseen maps.
- [Chess AI](https://github.com/adler1122/Chess) — a custom chess engine with a Pygame interface and search-based opponents.
- [IMDb sentiment classifier](https://github.com/MohamadRezaRS/imdb-sentiment-classifier) — a PyTorch text classification pipeline with custom vocabulary and sequence handling.
- [F1 PitWall](https://github.com/MohamadRezaRS/F1-PitWall) — pit-stop prediction with tabular models and a stacking ensemble.
