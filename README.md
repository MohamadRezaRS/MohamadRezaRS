# Hi, I'm Mohamad Reza 👋

I build projects in machine learning, data science, computer vision, and AI systems. My work ranges from research-style experiments and model evaluation to playable applications and end-to-end pipelines. Several projects began as coursework at K. N. Toosi University of Technology and grew into independent implementations.

## What I work on

- **Machine learning and data science:** predictive modeling, feature engineering, evaluation, and time-aware validation.
- **AI and language:** retrieval-augmented generation, text classification, and reinforcement learning.
- **Computer vision:** object tracking, geometric mapping, and video analytics.
- **Software engineering:** modular Python pipelines, command-line tools, and small web interfaces.
